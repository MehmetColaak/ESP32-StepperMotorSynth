# ESP32 MIDI Stepper Motor Synth

Plays MIDI notes on NEMA 17 stepper motors. One motor per MIDI channel, 5 voices.
ESP32 + A4988 drivers, tones generated by hardware timers (LEDC + MCPWM).

Inspired by [jzkmath/Arduino-MIDI-Stepper-Motor-Instrument](https://github.com/jzkmath/Arduino-MIDI-Stepper-Motor-Instrument).

## Hardware

- ESP32
- 5× A4988 driver + 5× NEMA 17
- 12V PSU
- 100µF cap per driver on VMOT/GND

## Wiring

STEP pins: GPIO 4, 5, 6, 7, 15. DIR pins: GPIO 16, 17, 18, 8, 3. EN not connected.
A4988 VDD from ESP32 3.3V, VMOT from 12V. All grounds common. Vref ~0.5–0.6V.

## MIDI

Raw MIDI bytes over USB serial. Channels 1–5 → motors 1–5.
Supported: note on/off, pitch bend (±2 st), CC 120/123.

## Changing motor count

Edit `STEP_PINS[]`/`DIR_PINS[]` in `src/main.cpp`. First 4 voices use LEDC, rest MCPWM.
Max 10 voices on ESP32-S3 (4 LEDC + 6 MCPWM timers), 14 on original ESP32.
Avoid GPIO 0, 19, 20, 26–32, 45, 46 on the S3 (GPIO 3 is a strapping pin but fine for DIR).

## Test firmware

- `pio run -e test-motor -t upload -t monitor`: runs each motor one revolution each way, in turn
- `pio run -e test-led -t upload`: blinks the onboard LED

After uploading, press RST if the board doesn't start.
